Signing secret

Every delivery is HMAC-SHA256 signed with this secret in the X-Webhook-Signature header, so the receiving system can verify it really came from here. Share it with whatever verifies the callback (a Zapier/n8n step, your own endpoint code — Slack's incoming webhooks don't check this, so it's not needed there).
